Changes to `storage.yml` need a restart; `/sb reload` keeps the current storage and says so.

| Key | Default | Meaning |
|---|---|---|
| `type` | `H2` | `H2` (a local file, the default), `MARIADB`, `MYSQL` or `POSTGRESQL`. Several servers sharing one MariaDB, MySQL or PostgreSQL database share their punishments. |
| `h2.file` | `sakurabans` | The H2 database file, in the plugin folder and without extension (`sakurabans` becomes `sakurabans.mv.db`). Only used with `H2`. |
| `host` | `localhost` | Database host (ignored with H2). |
| `port` | `0` | `0` uses the database's default port (3306, or 5432 for PostgreSQL); otherwise 1-65535. |
| `database` | `sakurabans` | The name of the database, which must already exist. |
| `username`, `password` | `sakurabans`, `''` | Credentials. |
| `table-prefix` | `sb_` | Prepended to every table name, so several plugins or networks can share a database: 1-16 characters of a-z, 0-9 and `_`, starting with a letter. Changing it later points SakuraBans at new, empty tables. |
| `schema` | `''` | PostgreSQL schema, a lower-case name; empty uses the default (`public`). |
| `properties` | `{}` | Extra JDBC connection properties of the driver in use, as `name: 'value'` pairs, for example `useSSL: 'true'`. |

## pool

| Key | Default | Meaning |
|---|---|---|
| `pool.maximum-size` | `10` | The most connections open at once (1 or more). |
| `pool.minimum-idle` | `2` | Connections kept open while idle (0 up to `maximum-size`). |
| `pool.connection-timeout` | `5s` | How long to wait for a free connection. |
| `pool.max-lifetime` | `30m` | How long a connection is kept before it is replaced. Keep it shorter than the database's own connection time limit. |

## sync

| Key | Default | Meaning |
|---|---|---|
| `sync.mode` | `NONE` | How several servers on one database tell each other about punishments: `NONE`, or `SQL` (polling a table, for networks; needs MariaDB, MySQL or PostgreSQL). Without it, a mute or unmute from another server reaches a player within about a minute, and a ban from another server when the player next joins. |
| `sync.poll-interval` | `2s` | How often SQL sync checks for news, from 250ms to 30s. |

See [Networks](/docs/guides/networks).
