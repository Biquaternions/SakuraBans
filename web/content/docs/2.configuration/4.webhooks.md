Only the server where something happens posts it, so a network posts each punishment once.
`/sb reload` applies changes.

| Key | Default | Meaning |
|---|---|---|
| `enabled` | `false` | Whether webhooks are sent at all. |
| `url` | `""` | The webhook URL routes use unless they name their own (Discord: Server settings > Integrations > Webhooks). An http(s) URL. |
| `username` | `SakuraBans` | The name the messages show. |
| `avatar-url` | `""` | The avatar (an http(s) URL), or empty for the webhook's own. |
| `include-silent` | `false` | Whether silent punishments are posted. Hidden ones never are. |

## Routes

One route per event: `ban`, `mute`, `warn`, `kick`, `unban`, `unmute`, `unwarn`, `void`,
`delete`, `edit` and `rollback`. An event without a route, or with `enabled: false`, is not
posted.

| Route key | Meaning |
|---|---|
| `enabled` | Whether this event is posted. |
| `url` | The route's own webhook URL; empty uses the top-level `url` (one of the two must be set). |
| `title` | The embed title. |
| `color` | The embed colour, `#rrggbb`. |
| `description` | The embed text. |
| `fields` | `name: text` pairs, at most 25, shown in this order. A field whose text comes out empty is left out. |

Texts may use Discord markdown and these placeholders: `{victim}` `{uuid}` `{address}` `{id}`
(the number) `{display_id}` (the id as `display.id-style` shows it) `{operator}` `{reason}`
`{duration}` `{expires}` `{type}` `{scope}` `{server}` (where it was issued) `{revoker}`
`{revoke_reason}` `{edit}` (what changed, `edit` only) and `{count}`. The `rollback` route only
knows `{victim}` (the staff member whose punishments were lifted), `{revoker}`,
`{revoke_reason}` and `{count}`.

```yaml
routes:
  ban:
    enabled: true
    url: ""
    title: Ban
    color: "#e74c3c"
    description: "{victim} was banned by {operator}"
    fields:
      Reason: "{reason}"
      Duration: "{duration}"
      Scope: "{scope}"
      Id: "#{display_id}"
```

Webhook URLs are secrets: anyone who has one can post to your channel.

## Overrides

Every key of this file can be overridden in the database, in global, a category or one server
(`webhooks:enabled`, `webhooks:url`, … and per route `webhooks:routes.<event>…`). A server without
an override keeps using this file. The URLs are **secrets**: `/sb settings list` masks them, they
never appear in logs, audit values or the editor's change lines, and the
[web editor](/docs/web-editor) only shows whether one is set. You can type a new URL there, clear
it, or publish a server's file values (the plugin copies them; the browser never sees them). The
editor also shows a preview of each route's embed.
