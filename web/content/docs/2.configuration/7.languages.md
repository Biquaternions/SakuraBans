Every message SakuraBans sends is in `lang/en_US.yml`, written in
[MiniMessage](https://docs.advntr.dev/minimessage/format.html). Only English ships.

- SakuraBans never rewrites the file. Keys missing there fall back to the built-in English
  text and are listed in the log at startup.
- To translate, copy the file to `lang/<locale>.yml` (for example `de_DE.yml`). Missing keys
  there fall back as well.
- `<prefix>` inserts the `prefix` message into any message, and `<plugin>` the `plugin` message
  (the plugin's name, a pink and white gradient by default; the prefix is built from it).
- The palette tags `<main>`, `<accent>`, `<highlight>` and `<danger>` colour the plugin's own
  replies. Their colours are defined once, under `palette` (`#rrggbb` or a colour name such as
  `light_purple`); a value that isn't a colour falls back to the built-in one with a warning.
  By default: `main` `#F591FF` for running text and labels, `accent` `#B891FF` for values (names,
  ids, counts), `highlight` `#FF91BF` for warnings and confirmations, `danger` red for errors. The
  help menu takes the palette at startup.
- What a punished player sees and the staff notices of punishments (`screen.*`, `victim.*`,
  `dialog.*`, `chat.*`, `notify.*`) use named colours instead, so each can be changed on its own.
- Values that come from players or staff (names, reasons) are always shown as plain text, so
  they can't inject formatting.
- A list value, or a block with line breaks, is a multi-line message (disconnect screens).

## Which locale is used

Exact locale → any file of the same language → `display.default-locale` → the built-in
English. Ban screens are shown before the client's locale is known, so they use
`display.default-locale`.

## Placeholders

Each message documents its placeholders in a comment above its section. The disconnect
screens (`screen.*`), for example, know `<victim>` `<created>` `<reason>` `<operator>`
`<duration>` `<remaining>` `<expires>` `<id>` `<display_id>` `<scope>` `<type>` `<server>`.
`<duration>` lists every unit; `<remaining>` only the largest and the one below it. A permanent
punishment shows `never` for `<expires>` and `permanent` for `<remaining>`.

## The default look

Replies start with the prefix, `SakuraBans ...🖉 ` (the name in its gradient). Ban and kick
screens show the name, a short rule, the player, issue date, staff member and reason, the expiry
(bans only) and the punishment's id. The mute notice and warnings in chat are a 7×7 banner of
`■` with an exclamation mark drawn in white squares (a space is narrower than `■` in
Minecraft's font, so it can't be left blank) and the text to its right; as a dialog, the banner
stands above the text. A long reason wraps onto the next chat line, below the banner's row.

## Overrides

A network can override single messages per locale in the database, through the
[web editor](/docs/web-editor), including locales that have no file. An override wins over the
file. `/sb messages list [locale]` shows the overrides and `/sb messages reset <locale> <key>`
(or `all`) removes them.
