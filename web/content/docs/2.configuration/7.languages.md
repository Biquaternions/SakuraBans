Every message SakuraBans sends is in `lang/en_US.yml`, written in
[MiniMessage](https://docs.advntr.dev/minimessage/format.html). Only English ships.

- SakuraBans never rewrites the file. Keys missing there fall back to the built-in English
  text and are listed in the log at startup.
- To translate, copy the file to `lang/<locale>.yml` (for example `de_DE.yml`). Missing keys
  there fall back as well.
- `<prefix>` inserts the `prefix` message into any message.
- Values that come from players or staff (names, reasons) are always shown as plain text, so
  they can't inject formatting.
- A list value, or a block with line breaks, is a multi-line message (disconnect screens).

## Which locale is used

Exact locale → any file of the same language → `display.default-locale` → the built-in
English. Ban screens are shown before the client's locale is known, so they use
`display.default-locale`.

## Placeholders

Each message documents its placeholders in a comment above its section. The disconnect
screens (`screen.*`), for example, know `<reason>` `<operator>` `<duration>` `<remaining>`
`<expires>` `<id>` `<display_id>` `<scope>` `<type>` `<server>`. `<duration>` lists every
unit; `<remaining>` only the largest and the one below it.

## Overrides

A network can override single messages per locale in the database, through the
[web editor](/docs/web-editor), including locales that have no file. An override wins over the
file. `/sb messages list [locale]` shows the overrides and `/sb messages reset <locale> <key>`
(or `all`) removes them.
