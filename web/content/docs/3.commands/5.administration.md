`/sb` is `/sakurabans`; the labels can be changed in `commands.labels`. Commands marked
*confirm* first say what they would do and need the same command again with `--confirm`
within 30 seconds.

## General

| Command | Permission | Meaning |
|---|---|---|
| `/sb help [query]` | `sakurabans.help` | The commands you may use. |
| `/sb status` | `sakurabans.admin.status` | SakuraBans status, including the instances of the network it knows (the instance registry). |
| `/sb reload` | `sakurabans.admin.reload` | Reload the configuration and messages. Lists every problem if something is invalid, and the database overrides that exist. |

## Punishments

| Command | Permission | Meaning |
|---|---|---|
| `/sb edit <id> reason <text…>` | `sakurabans.<type>.edit`, or `.edit.own` for your own | Change the reason. |
| `/sb edit <id> duration <duration>` | as above | Set a new duration. |
| `/sb edit <id> extend <duration>` | as above | Extend it. |
| `/sb edit <id> scope <scope>` | as above | Move it to another scope. |
| `/sb evidence <id> add <url>` / `remove <url>` | as above | Attach or detach evidence. |
| `/sb delete <id>` *(confirm)* | `sakurabans.<type>.delete` | Delete a punishment from the history. |
| `/staffrollback <staff> <since> [-r <reason…>]` *(confirm)* | `sakurabans.admin.staffrollback` | Lift what a staff member issued within the given time. |
| `/prunehistory <target> [--older-than <duration>]` *(confirm)* | `sakurabans.admin.prunehistory` | Delete a player's ended punishments. |

## Lockdown

| Command | Permission | Meaning |
|---|---|---|
| `/lockdown [-g\|--server\|--category\|--scope] [-d <duration>] [-r <reason…>]` | `sakurabans.admin.lockdown` | Keep new players out, everywhere or in a scope, optionally for a while and with a reason. |
| `/lockdown end [scope flags]` | `sakurabans.admin.lockdown` | End it. |
| `/lockdown status` | `sakurabans.admin.lockdown` | Whether a lockdown is active. |

`sakurabans.lockdown.bypass` lets a player join during a lockdown. `lockdown.persist` decides
whether it survives a restart.

## Allow list

Accounts and addresses that address bans don't reach.

| Command | Permission |
|---|---|
| `/sb allow add <target> [note…]` | `sakurabans.admin.allow` |
| `/sb allow remove <target>` | `sakurabans.admin.allow` |
| `/sb allow list` | `sakurabans.admin.allow` |

## Templates, settings and messages

| Command | Permission | Meaning |
|---|---|---|
| `/sb templates list` | `sakurabans.admin.templates` | The templates. |
| `/sb templates import` *(confirm)* | `sakurabans.admin.templates` | Create or update every template in `templates.yml`. |
| `/sb templates export` | `sakurabans.admin.templates` | Write them to `exports/templates-<time>.yml`. |
| `/sb settings list [scope]` | `sakurabans.admin.settings` | Settings overridden in a scope (global when none is named), with file and database values. |
| `/sb settings reset <key>\|all [scope]` | `sakurabans.admin.settings` | Remove an override (`all` needs `--confirm`). |
| `/sb settings publish` | `sakurabans.admin.settings` | Show this server's file values that differ from global; `--confirm` writes them as global overrides. |
| `/sb messages list [locale] [scope]` | `sakurabans.admin.messages` | Messages overridden in the database. |
| `/sb messages reset <locale> <key>\|all [scope]` | `sakurabans.admin.messages` | Remove an override (`all` needs `--confirm`). Locales as `en_US` or `en-US`. |
| `/sb editor [settings\|messages\|templates]` | `sakurabans.editor` | Open the [web editor](/docs/web-editor). |
| `/sb applyedits <code>` | `sakurabans.editor` (and the section permissions) | Apply changes saved in the web editor. |

## Data and imports

| Command | Permission | Meaning |
|---|---|---|
| `/sb gdpr export <target>` | `sakurabans.admin.gdpr` | Export what SakuraBans stores about a player. |
| `/sb gdpr erase <target>` *(confirm)* | `sakurabans.admin.gdpr` | Erase a player's data. |
| `/sb import <source> [--dry-run]` *(confirm)* | `sakurabans.admin.import` | Import from another plugin; see [Importing](/docs/guides/importing). |
