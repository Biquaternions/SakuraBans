## Shape

```
/ban <target> [flags…] [-r <reason…>]
/tempban <target> <duration> [flags…] [-r <reason…>]
```

After the target there are only flags. `-r`/`--reason` takes the rest of the line, so it comes
last; everything after it is reason text. Without it the configured default reason (or the
template's) applies. Bare words after the target are a syntax error.

## Targets

| Target | Example | Meaning |
|---|---|---|
| A player name | `Steve` | Resolved through the names SakuraBans has seen (and, on Paper, a profile lookup unless `players.remote-lookup` is off). |
| A UUID | `ec561538-f3fd-461d-aff5-086b22154bce` | That account. |
| An address | `203.0.113.7` | An address punishment (needs the `ip` flag permission). |
| A range | `203.0.113.0/24`, `203.0.*.*` | An address range (needs `sakurabans.<type>.range`). |
| `#<id>` | `#42` | A punishment id, where a command accepts one. |

## Commands

| Command | Arguments | Permission |
|---|---|---|
| `/ban` | `<target>`, optional `-d <duration>` | `sakurabans.ban` |
| `/tempban` | `<target> <duration>` | `sakurabans.ban` or `sakurabans.ban.temporary` |
| `/ipban` | `<target>`: bans the player together with their address | `sakurabans.ban` |
| `/mute` | `<target>`, optional `-d <duration>` | `sakurabans.mute` |
| `/tempmute` | `<target> <duration>` | `sakurabans.mute` or `sakurabans.mute.temporary` |
| `/ipmute` | `<target>`: mutes the player together with their address | `sakurabans.mute` |
| `/warn` | `<target>`, optional `-d <duration>` | `sakurabans.warn` |
| `/kick` | `<target>` | `sakurabans.kick` |

Without a duration a ban or mute is permanent; a warning lasts `warnings.expire-after`.

## Flags

| Flag | On | Permission | Meaning |
|---|---|---|---|
| `-r`, `--reason <text…>` | all | — | The reason (the rest of the line). |
| `-d`, `--duration <time>` | ban, mute, warn, ipban, ipmute | — | The duration (not on kicks or the temp commands). |
| `-t`, `--template <name>` | all | `sakurabans.template.<name>` when the template requires it | Use a preset of the command's type, or a reason shortcut. A preset with its own duration refuses `-d` and the temp commands. Ladders go through `/punish`. |
| `-s`, `--silent` | all | `sakurabans.<type>.silent` | Only staff with `sakurabans.<type>.notify.silent` are told. |
| `--hide` | all | `sakurabans.<type>.hide` | No staff notice at all; never posted to webhooks. |
| `-I`, `--ip` | ban, mute, warn, kick | `sakurabans.<type>.ip` | Also punish the player's current address. |
| `--shadow` | mute, tempmute, ipmute | `sakurabans.mute.shadow` | A shadow mute: the player's messages are shown to them only. |
| `-g`, `--global` | all | scope permission | Applies everywhere. |
| `--server <name>` | all | scope permission | Applies on one server. |
| `--category <name>` | all | scope permission | Applies on a category of servers. |
| `--scope <scope>` | all | scope permission | `global`, `local`, `server:<name>` or `category:<name>`. |
| `-o`, `--override` | ban, mute, warn | `sakurabans.<type>.override` | Replace an active punishment of the same type in the same scope. |
| `-N`, `--if-longer` | ban, mute, warn | `sakurabans.<type>.override` | Replace it only if the new one is longer. |
| `-e`, `--evidence <url>` | all | `sakurabans.<type>.evidence` | Attach evidence (an http(s) URL); repeatable. |
| `--skip` | all | `sakurabans.<type>.skip` | Store the punishment without applying it to online players right away. |
| `--sender <name>`, `--sender-uuid <uuid>` | all | console only | Issue it in someone else's name. `--sender-uuid` needs `--sender`. |

Scope permissions only matter with `scopes.require-permissions: true`; see [Scopes](/docs/guides/scopes).

## Ladders

```
/punish <target> <ladder> [flags…] [-r <reason…>]
```

Applies the next step of a [ladder](/docs/guides/templates#ladders) to the target: the step
decides the type and the duration, or punishes nothing and only runs its actions (`none`).
`/punish` needs `sakurabans.punish` (and `sakurabans.template.<name>` when the ladder requires
it), not the permission of the step's type. It takes `-s`, `--hide`, the scope flags,
`--sender`/`--sender-uuid` (console), `--skip`, `-e`, `-I`, `-o`, `-N` and `-r`; each needs
`sakurabans.punish.<flag>` (`-N` the `override` node). The ladder's name completes after the
target.

## Examples

```
/ban Steve -d 7d -r Griefing at spawn
/tempmute Alex 1h -s -r Spam
/ban Steve --template hacking -r caught on camera
/punish Steve misconduct -s
/ban 203.0.113.0/24 --server lobby -r Bot attack
/warn Steve -e https://example.org/clip.mp4 -r Chat abuse
```
