---
title: Importing from other plugins
description: Moving punishments from LiteBans, LibertyBans, AdvancedBan, BanManager, vanilla or another SakuraBans database.
navigation:
  icon: i-lucide-import
---

```
/sb import <source> [--dry-run] [--confirm]
```

Needs `sakurabans.admin.import`. `<source>` is one of `self`, `libertybans`, `litebans`,
`advancedban`, `banmanager` and `vanilla`; tab completion lists them.

1. Fill in the source's section of [import.yml](/docs/configuration/import). The file is read
   every time an import runs.
2. Stop the other plugin, or at least make sure it doesn't write during the import. File
   databases (H2, HSQLDB) can't be open in two programs at once.
3. Run `/sb import <source> --dry-run` to see what would be imported.
4. Run `/sb import <source>`; it says what it will do, then run it again with `--confirm`
   within 30 seconds.

Each import runs once at a time across the network. Running it again skips what it already
imported, so an interrupted import can simply be repeated.

## Notes per source

- **self**: moves a whole SakuraBans database (punishments, players, templates, allow list,
  audit log, ...) into this one, for example from H2 to MariaDB. This database must still be
  empty, and both must be of the same SakuraBans version.
- **litebans**: older LiteBans versions wrote an H2 1.x file, which can't be opened; move
  LiteBans to MySQL or MariaDB first.
- **advancedban**: its tables have no prefix.
- **vanilla**: reads `banned-players.json` and `banned-ips.json` of the server.
